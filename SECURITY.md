# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/westonkd/sprint/security/advisories/new)
rather than opening a public issue.

You can expect an acknowledgement within a week. Please include a description of the issue, steps
to reproduce, and the affected version or commit.

## Scope

Sprint registers browser-side WebMCP tools that act on behalf of AI agents. Reports about tools
exposing data they should not, acting on disabled or hidden controls, or leaking secret values into
the agent-readable surfaces are in scope and especially welcome.
